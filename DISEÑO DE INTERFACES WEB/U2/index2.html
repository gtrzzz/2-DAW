Etiqueta DL
Especifica una lista de definiciones, es decir, una lista de términos y sus definiciones asociadas.
Etiqueta DT
Representa un término definido por el siguiente "dd".
Contenedor PRE y blockquote 
                    Contenido preformateado       Conserva los espacios,
            los saltos de línea y los tabuladores del texto original.
Blockquote es para representar un contenido citado desde otra fuente

P es para texto normal
