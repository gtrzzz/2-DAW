Actividad 1: código JavaScript en un fichero externo separado

RA1 – CE 1.e · Verificación de los mecanismos de integración de los lenguajes de marcas con los lenguajes de programación de clientes Web.

Comprobación

Al cargar esta página aparece un cuadro de alerta con el texto hola. Pulsa "Aceptar" para seguir leyendo: el alert() es modal, así que el navegador congela la ejecución hasta que se acepta.

Código del archivo HTML

<!DOCTYPE html>
<html>
<head>
  <title>Myfpschool</title>
  <!-- Enlace al fichero script.js -->
  <script src="script.js"></script>
</head>
<body>
</body>
</html>

Código del archivo ./js/script.js

function diAlgo() {
  alert("hola"); // Muestra un cuadro modal emergente con el texto "hola"
}

// Invocacion directa al cargarse el fichero
diAlgo();

Sobre la ruta del atributo src

El enunciado pide que los dos archivos estén en la misma carpeta, y en ese caso la ruta es src="script.js". Este proyecto aplica la buena práctica profesional que indica el tema: guardar los scripts en una carpeta propia llamada js, de modo que la ruta relativa es src="./js/script.js".

Las tres formas de escribir la ruta son equivalentes desde la raíz del proyecto, pero es preferible usar siempre la barra inicial ./ porque deja claro que se trata de una ruta relativa y no absoluta: 

<script src="script.js"></script>        <!-- misma carpeta -->
<script src="./js/script.js"></script>   <!-- subcarpeta js (recomendado) -->
<script src="/js/script.js"></script>        <!-- desde la raiz del servidor -->

Ventajas técnicas de los ficheros externos

VentajaExplicación
Velocidad de carga y memoria caché El navegador descarga el .js una única vez y lo guarda en su caché. Si el usuario navega a otra página del mismo sitio que use ese script, no lo vuelve a descargar por la red: menos ancho de banda y respuesta más rápida.
Independencia de facetas (modularidad) Se separa estrictamente el contenido (.html) del comportamiento dinámico (.js). Diseñadores y programadores pueden trabajar a la vez sobre el mismo proyecto sin pisarse el código.
Mantenimiento y reutilización Para corregir una función basta con modificar un solo archivo, y el cambio se refleja en todas las páginas que lo referencian.
Organización Las empresas y los desarrolladores experimentados agrupan los recursos en carpetas dedicadas: css/, js/, img/.

Comprobación en la pestaña Network

Con F12 abierto, en la pestaña Network (Red), recarga la página. Debería aparecer la petición ./js/script.js con estado 200 OK, junto con ./css/estilos.css. Si apareciera 404 Not Found, la ruta relativa src estaría mal escrita.
