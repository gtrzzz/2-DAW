Práctica de laboratorio guiada

Esta es la reorganización de un proyecto con la estructura profesional de carpetas. El bloque de código que cambiaba el color del botón estaba embebido dentro de este mismo archivo HTML y se ha trasladado a ./js/logica.js, enlazado desde el <head> con la ruta relativa ./js/logica.js.

Estructura resultante

mi_proyecto/
├── css/
│   └── estilos.css
├── js/
│   └── logica.js
└── index.html          <-- esta pagina

Demostración: el botón cambia de color

Pulsa el botón y observa cómo js/logica.js cambia su color:

(la traza de JavaScript aparecerá aquí y en la consola)

Código del index.html completo

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Mi proyecto</title>
    <link rel="stylesheet" href="./css/estilos.css">
    <script defer src="./js/logica.js"></script>
  </head>
  <body>
    <h1>Práctica de laboratorio guiada</h1>
    <button type="button" id="btnColor">Cambia mi color</button>
    <p id="mensaje"></p>
  </body>
</html>

Cómo se ha trasladado el bloque de script

El código embebido original era:

<script>
  function cambiarColor() {
    document.getElementById("btnColor").style.backgroundColor = "green";
  }
  document.getElementById("btnColor").addEventListener("click", cambiarColor);
</script>

Ahora esa misma lógica vive en ./js/logica.js y el HTML solo la enlaza:

<script defer src="./js/logica.js"></script>

Comprobación en la pestaña Network (Red)

  1. Abre las herramientas de desarrollador con F12.
  2. Sitúate en la pestaña Network (Red).
  3. Recarga la página con F5.
  4. Comprueba que aparecen estas dos peticiones con estado 200 OK:
Recurso solicitadoTipoEstado esperado
./css/estilos.cssstylesheet200 OK
./js/logica.jsscript200 OK
./index.htmldocument200 OK

Si alguno devolviera 404 Not Found, la ruta relativa del atributo src o del href estaría mal escrita: hay que comprobar que desde index.html el camino ./js/logica.js existe realmente.

Nota: si abres el archivo con doble clic (file://), la pestaña Network puede mostrar los recursos con estado (from disk cache) o sin código de estado. Para ver el 200 OK real hay que servir la carpeta con un servidor local, por ejemplo con la extensión Live Server de Visual Studio Code.
