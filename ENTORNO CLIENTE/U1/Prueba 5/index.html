Errores frecuentes al integrar varios ficheros .js

Todos los <script> externos de una misma página se ejecutan en el mismo ámbito global. Eso tiene una consecuencia muy fácil de pasar por alto:

  • Dos ficheros que declaren el mismo const o let de primer nivel producen un SyntaxError: Identifier 'X' has already been declared y el segundo fichero entero deja de ejecutarse.
  • Dos function con el mismo nombre no dan error: la segunda sobrescribe silenciosamente a la primera, y el fallo solo se manifiesta en forma de comportamiento raro.

Por eso, en este proyecto cada .js usa nombres propios (ejecutarCalculoDias, ejecutarCalculoMes, registrarIdioma…). La otra solución, más limpia, es envolver cada fichero entre paréntesis para crear un ámbito propio: 

(function () {
  // todo lo declarado aqui dentro es privado de este fichero
  const TOTAL_PREGUNTAS = 7;
  // ...
})();

Esa misma construcción, escrita con la sintaxis moderna, es el módulo ES (type="module"), que además da a cada fichero su propio ámbito de forma nativa, pero obliga a cargar los ficheros con <script type="module" src="...">.
