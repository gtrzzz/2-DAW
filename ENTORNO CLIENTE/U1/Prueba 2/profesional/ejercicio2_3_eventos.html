Ejercicios 2 y 3: captura del evento clic

RA1 – CE 1.a · Mecanismos de ejecución de los navegadores Web: el modelo de eventos y los métodos de salida disponibles.

Enunciado del ejercicio 2

Implementar una página que capture el evento clic de un botón para emitir una traza informativa a las herramientas de desarrollo mediante console.log().

Enunciado del ejercicio 3

Modificar el ejercicio anterior sustituyendo la escritura en el párrafo por ventanas de aviso emergentes modales utilizando el método window.alert().

Código del fichero externo ./js/ej2_3_eventos.js

function trazarEnConsola() {
  console.log("Se ha pulsado el botón");
}

function mostrarAlerta() {
  window.alert("Se ha pulsado el botón");
}

document.addEventListener("DOMContentLoaded", () => {
  document.getElementById("btnConsola").addEventListener("click", trazarEnConsola);
  document.getElementById("btnAlerta").addEventListener("click", mostrarAlerta);
});

Comparación de los dos mecanismos de salida

Aspecto console.log() window.alert()
Destinatario El desarrollador (pestaña Console) El usuario final
¿Interrumpe la página? No, la ejecución continúa Sí, es modal y bloqueante
Uso adecuado Depuración y diagnóstico Avisos y mensajes de confirmación
Devuelve un valor Sí, lo que se le pase (útil con const x = console.log(1)) No, siempre undefined

Por qué addEventListener() y no el atributo onclick

<!-- Enfoque embebido: el codigo viaja dentro del HTML -->
<button onclick="console.log('Se ha pulsado el boton')">¡Dale!</button>

<!-- Enfoque externo: el codigo vive en un .js y se enlaza al elemento -->
<button id="btnConsola">¡Dale!</button>
<script src="./js/ej2_3_eventos.js"></script>

Ventajas de addEventListener():

  • Permite registrar varios manejadores para el mismo evento.
  • Permite quitarlo con removeEventListener().
  • Permite indicar opciones como { once: true }.
  • Separa la estructura del documento de la lógica.
