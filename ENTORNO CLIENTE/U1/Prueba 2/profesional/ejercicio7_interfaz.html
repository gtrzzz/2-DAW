Ejercicio 7: interfaz de usuario

RA1 – CE 1.a · Combinación de los distintos mecanismos de salida del navegador: console.log(), innerHTML con .style.backgroundColor y window.alert().

Enunciado

Diseñar una interfaz compuesta por un titular <h1>, un párrafo <p id="estado">Sistema en espera</p> y tres botones:

  • Botón 1 (Consola): emite una traza mediante console.log() indicando la hora del sistema.
  • Botón 2 (Estilo): modifica el color de fondo del párrafo a verde y su texto a "Sistema Activo" mediante innerHTML y .style.backgroundColor.
  • Botón 3 (Alerta): lanza un cuadro modal mediante window.alert() avisando de que el proceso ha concluido.

Código del fichero externo ./js/ej7_interfaz.js

function botonConsola() {
  const hora = new Date().toLocaleTimeString();
  console.log("Hora del sistema: " + hora);
}

function botonEstilo() {
  const estado = document.getElementById("estado");
  estado.innerHTML = "Sistema Activo";
  estado.style.backgroundColor = "green";
}

function botonAlerta() {
  window.alert("El proceso ha concluido.");
}

document.addEventListener("DOMContentLoaded", () => {
  document.getElementById("btnConsola").addEventListener("click", botonConsola);
  document.getElementById("btnEstilo").addEventListener("click", botonEstilo);
  document.getElementById("btnAlerta").addEventListener("click", botonAlerta);
});

Qué demuestra cada botón

La hora del sistema se obtiene con new Date().toLocaleTimeString(), que devuelve la hora local en el formato del usuario. Con toLocaleTimeString("es-ES") se forzaría el formato español, y con toISOString() se obtendría la hora universal en UTC.
