Ejercicio 8: test interactivo

RA1 – CE 1.a · Evaluación de la respuesta del usuario y modificación dinámica de estilos mediante la propiedad .style.color.

Enunciado

Desarrollar un test interactivo de siete preguntas con botones «Verdadero» y «Falso». Cuando el usuario hace clic, el script evalúa el acierto y modifica la propiedad de estilo .style.color = "green" (acierto) o .style.color = "red" (error).

Cómo se declaran las respuestas correctas

Cada bloque <div class="pregunta"> lleva un atributo data-correcta con el valor real de la frase. El JavaScript lee ese atributo y lo compara con la respuesta que pulses, de modo que la lógica no está escrita a mano: se pueden añadir preguntas nuevas sin tocar el .js. 

<div class="pregunta" data-numero="1" data-correcta="true"
     data-enunciado="El sol es una estrella.">
  <p>Pregunta 1: El sol es una estrella.</p>
  <button type="button" data-respuesta="true">Verdadero</button>
  <button type="button" data-respuesta="false">Falso</button>
</div>

Test

Respondidas: 0 / 7 | Aciertos: 0

Responde a una pregunta para ver el resultado.

Pregunta 1: El sol es una estrella.

Pregunta 2: La capital de Francia es Berlín.

Pregunta 3: El agua hierve a 100 grados Celsius a nivel del mar.

Pregunta 4: La Tierra es plana.

Pregunta 5: La velocidad de la luz es de aproximadamente 300.000 km/s.

Pregunta 6: La capital de España es Madrid.

Pregunta 7: La fórmula química del agua es H2O.

Lógica del ejercicio

function comprobarRespuesta(boton) {
  const respuestaElegida = boton.dataset.respuesta === "true";
  const bloque = boton.closest(".pregunta");
  const respuestaCorrecta = bloque.dataset.correcta === "true";
  const acierto = respuestaElegida === respuestaCorrecta;

  boton.style.color = acierto ? "green" : "red";
  boton.style.fontWeight = "bold";

  // se resaltan ambas respuestas, no solo la pulsada
  bloque.querySelectorAll("button").forEach((otro) => {
    if (otro !== boton) {
      otro.style.color = "";
      otro.style.fontWeight = "";
    }
  });
}

Prioridad de los estilos

El color de los botones se escribe con boton.style.color, es decir, en el estilo en línea del elemento. En la cascada de CSS, el estilo en línea solo lo puede ganar una regla con !important, así que el JavaScript manda sobre la hoja css/estilos.css sin necesidad de ninguna regla adicional.
