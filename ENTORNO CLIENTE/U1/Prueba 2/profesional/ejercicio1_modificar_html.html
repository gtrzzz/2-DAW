Ejercicio 1: modificar el código HTML

RA1 – CE 1.a · Capacidades y mecanismos de ejecución de código de los navegadores Web. Acceso y modificación del DOM.

Enunciado

Modificar el contenido de un párrafo del documento mediante document.getElementById(...) e innerHTML. Añadir un segundo botón que, al pulsarlo, cambie también el texto del encabezado <h1> con el mismo mecanismo.

Código del HTML

<h1 id="h1cambio">Modificando el código HTML</h1>
<p id="prueba">Modificando el contenido.</p>
<button type="button" id="btnParrafo">¡Dale!</button>
<button type="button" id="btnEncabezado">¡Dale al segundo botón!</button>

Código del fichero externo ./js/ej1_modificar_html.js

function cambiarParrafo() {
  const parrafo = document.getElementById("prueba");
  parrafo.innerHTML = "CAMBIANDO el contenido!";
}

function cambiarEncabezado() {
  const encabezado = document.getElementById("h1cambio");
  encabezado.textContent = "CAMBIANDO el encabezado!";
}

document.addEventListener("DOMContentLoaded", () => {
  document.getElementById("btnParrafo").addEventListener("click", cambiarParrafo);
  document.getElementById("btnEncabezado").addEventListener("click", cambiarEncabezado);
});

Diferencia con los apuntes originales

Los apuntes resolvían este ejercicio escribiendo el código directamente dentro del atributo onclick del botón: 

<button onclick="document.getElementById('prueba').innerHTML = '...'">
  ¡Dale!
</button>

El resultado es exactamente el mismo, pero el enfoque embebido tiene tres inconvenientes: mezcla la lógica con el marcado, no se puede reutilizar en otra página y complica el mantenimiento. Aquí la lógica está en ./js/ej1_modificar_html.js, enlazado con addEventListener(), que además permite registrar más de un manejador para el mismo evento.
