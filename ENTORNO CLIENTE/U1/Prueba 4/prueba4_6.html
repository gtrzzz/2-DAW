Ejercicio 6: ventajas de usar JavaScript en el desarrollo web moderno

RA1 – CE 1.d · Análisis de ventajas y desventajas de la programación de guiones sobre la programación tradicional.

Enunciado

Describe las ventajas más importantes de usar JavaScript en el desarrollo web moderno.

Ventajas analizadas

1. Es el único lenguaje que ejecuta el navegador

Ningún otro lenguaje puede ejecutar lógica en el cliente sin instalar complementos o máquinas virtuales. JavaScript es el estándar de facto (norma ECMA-262) y todos los navegadores lo implementan, así que no hay que preocupar de la segmentación del mercado.

Consecuencia práctica: la lógica de la interfaz se escribe una sola vez y funciona en Chrome, Firefox, Safari, Edge, en móviles, en tabletas y en sistemas embebidos, sin mantener varias versiones del mismo código.

2. Portabilidad y ubicuidad gracias al anfitrión

El mismo archivo .js se ejecuta en un ordenador de sobremesa, en un portátil, en una tableta y en un teléfono inteligente sin recompilar nada, porque el código no se compila para una plataforma concreta: lo interpreta el navegador. Es la ventaja estructural de los lenguajes de script frente a los compilados nativos, donde un binario de C++ para Windows no se ejecuta en Linux.

3. Sencillez y curva de aprendizaje rápida

Los lenguajes de script se diseñaron expresamente para ser fáciles de usar: no exigen declaraciones de tipo, ni jerarquía de clases obligatoria, ni compilación previa. Todo lo que necesita un programador para pasar de cero a una página interactiva cabe en un día de estudio.

4. Agilidad en el ciclo de desarrollo

No hay fase de compilación ni de enlazado. Un cambio en el código fuente se verifica recargando la página. En un proyecto en C++ el ciclo real entre escribir y probar incluye compilar, enlazar y, si hay errores, repetir el proceso. Esa comodidad es la razón por la que casi todo el prototipado web se hace en JavaScript.

5. Integración natural con HTML y CSS

Se incrusta directamente entre etiquetas del documento mediante <script> o se enlaza con ficheros externos. Al no necesitar dependencias ni configuración, es el complemento natural del lenguaje de marcas que se estudia en este módulo: el mismo proyecto contiene la estructura y el comportamiento, o se separan en .html y .js sin ninguna herramienta intermedia.

6. Ecosistema, librerías y comunidad

JavaScript dispone del ecosistema más grande del sector: frameworks de interfaz (React, Vue, Angular), uso en servidor con Node.js, Deno o Bun, y WebAssembly, que permite llevar lenguajes tradicionales como C++, Rust o Go también al cliente cuando hace falta rendimiento nativo.

7. Control total de la interfaz sin recargar

El modelo basado en eventos y el acceso al DOM permiten modificar la página en caliente: cambiar textos, colores, imágenes, clases CSS o mostrar y ocultar elementos sin una sola petición al servidor. Eso hace posibles interfaces que en los años noventa exigían complementos como Flash, y que hoy son nativas de cualquier web.

8. Rendimiento razonable gracias a los motores modernos

Aunque el lenguaje se interpreta, los motores actuales (V8, SpiderMonkey, JavaScriptCore) aplican compilación en tiempo real (JIT) a las funciones que se repiten, de modo que la desventaja de rendimiento frente a C++ es bastante menor de lo que sugiere la definición clásica. En la mayoría de los casos de una web, el cuello de botella real es la red, no el intérprete.
