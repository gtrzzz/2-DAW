Complemento: métodos del objeto Date

RA1 – CE 1.d · Ejemplo práctico de la ventaja de los lenguajes de script: reutilizar componentes preexistentes del sistema anfitrión. El navegador ya trae un objeto Date completo con conversores, getters y setters; un lenguaje tradicional tendría que desarrollar esa librería desde cero.

1. Naturaleza del objeto

En JavaScript la fecha no es un tipo primitivo: es una instancia del objeto nativo Date. Por dentro almacena un único entero, los milisegundos desde la época Unix (1 de enero de 1970 00:00:00 UTC). Un valor positivo indica instantes posteriores a esa fecha y uno negativo, anteriores. 

const tiempoActualMs = Date.now();  // timestamp actual sin instanciar nada
// Ejemplo: 1790591037183

1 dia = 24 h * 60 min * 60 s * 1000 ms = 86.400.000 ms

La fecha es una instantánea congelada: no avanza sola. Para tener la hora actual hay que crear un objeto nuevo o llamar a Date.now().

2. Conversión y salida de la fecha actual

Estos seis métodos hacen la misma tarea con distintos formatos y destinatarios. La diferencia entre ellos no es cosmética: elegir el correcto evita errores al intercambiar datos con el exterior.

Método Estándar Salida típica Cuándo usarlo
toString()Texto local completoMon Sep 28 2026 12:23:57 GMT+0200 (CEST)Depuración rápida, conversión por defecto
toDateString()Solo fecha legibleMon Sep 28 2026Interfaces sin detalle de horas
toTimeString()Solo hora con huso12:23:57 GMT+0200 (CEST)Registros de eventos horarios
toISOString()ISO 8601 en UTC2026-09-28T10:23:57.000ZIntercambio con APIs y bases de datos
toUTCString()HTTP / RFC 7231Mon, 28 Sep 2026 10:23:57 GMTCabeceras HTTP y cookies
toLocaleDateString()Localización del usuario28/9/2026 (es-ES)Interfaz de usuario final

Regla práctica: toISOString() para hablar con el servidor, toLocaleDateString() para hablar con el usuario y toString() para depurar. Nunca usar toString() para enviar datos a una API, porque su formato depende del idioma del navegador.

3. Getters y setters

const f = new Date(2026, 8, 28, 14, 45, 10); // 28 de septiembre de 2026

// LECTURA
f.getFullYear();   // 2026
f.getMonth();      // 8  -> septiembre, porque enero es 0
f.getDate();       // 28 -> dia del mes (este si empieza en 1)
f.getDay();        // 1  -> dia de la semana (0 domingo ... 6 sabado)
f.getHours();      // 14
f.getMinutes();    // 45
f.getSeconds();    // 10
f.getTime();       // timestamp en ms (equivalente a valueOf())

// ESCRITURA
f.setFullYear(2027);
f.setMonth(0);
f.setDate(15);
