Ejercicio 3: calculadora del último día de un mes

RA1 – CE 1.d · se explota el comportamiento de desbordamiento del objeto Date: en lugar de escribir una tabla de días por mes, se aprovecha que el motor ya sabe calcular el desbordamiento.

Enunciado

Gracias al comportamiento de desbordamiento, pasar el día 0 al constructor permite obtener el último día del mes inmediatamente anterior. Crear la función obtenerUltimoDiaMes(año, mes) donde mes se pase en formato humano (1 enero, 2 febrero, …) y que retorne el número entero de días que tiene ese mes.

Implementación

function obtenerUltimoDiaMes(anio, mes) {
  // "dia 0" del mes que sigue al indicado = ultimo dia del mes pedido.
  // Ejemplo: mes = 12 (diciembre) -> new Date(2026, 12, 0) = 31 de diciembre de 2026
  return new Date(anio, mes, 0).getDate();
}

Por qué funciona el truco del día 0

Los meses en JavaScript van de 0 a 11. Como el constructor acepta mes en base 0, pasar el mes humano 12 equivale a pasar el índice 12, que ya es "enero del año siguiente". Al combinarlo con día 0, el motor retrocede un día desde el 1 de enero y cae precisamente en el 31 de diciembre.

El desbordamiento se usa como una suma y resta silenciosa:

new Date(2026, 12, 0)  // dia 0 de "enero de 2027" -> 31 dic 2026
new Date(2026,  2, 0)  // dia 0 de "marzo de 2026"    -> 28 feb 2026
new Date(2024,  2, 0)  // dia 0 de "marzo de 2024"    -> 29 feb 2024 (bisiesto)
new Date(2026,  4, 0)  // dia 0 de "mayo de 2026"     -> 30 abr 2026

No hace falta ninguna lógica especial para el mes bisiesto: el motor ya lo tiene en cuenta, y por eso la función vale para cualquier año.

Bisiesto, un detalle importante

Febrero tiene 28 días, salvo en los años bisiestos, en los que tiene 29. Un año es bisiesto si es divisible por 4, excepto los años divisibles por 100 (que no lo son) salvo los divisibles por 400 (que sí lo son). 

function esBisiesto(anio) {
  return anio % 400 === 0 || (anio % 4 === 0 && anio % 100 !== 0);
}

esBisiesto(2024); // true  -> febrero de 29 dias
esBisiesto(2026); // false -> febrero de 28 dias
esBisiesto(1900); // false -> divisible por 100 pero no por 400
esBisiesto(2000); // true  -> divisible por 400

Esta función es un complemento de obtenerUltimoDiaMes: no hace falta para calcular el último día (el motor ya lo resuelve), pero sí para saber si ese mes es de 28 o de 29 días.
