Ejercicio 4: formateador manual de fechas sin librerías

RA1 – CE 1.d · Ventaja de los lenguajes de script: su sintaxis reducida permite resolver en pocas líneas lo que en un lenguaje tradicional exigiría tipos, sobrecarga de operadores y concatenación de cadenas. Aquí además se demuestra el método de cadenas padStart().

Enunciado

Escribir una función formatearFechaEspanola(fecha) que reciba un objeto Date y devuelva una cadena con el formato exacto DD/MM/YYYY HH:mm. Los números menores de 10 deben incluir un cero a la izquierda (01, 02, … 09) utilizando el método de cadenas .padStart(2, "0").

Implementación

function formatearFechaEspanola(fecha) {
  const dia = String(fecha.getDate()).padStart(2, "0");
  const mes = String(fecha.getMonth() + 1).padStart(2, "0"); // +1 porque el mes es base 0
  const anio = fecha.getFullYear();
  const hora = String(fecha.getHours()).padStart(2, "0");
  const minuto = String(fecha.getMinutes()).padStart(2, "0");

  return `${dia}/${mes}/${anio} ${hora}:${minuto}`;
}

El método padStart()

string.padStart(length, string) devuelve una nueva cadena de longitud total length, rellenando por el principio (por la izquierda) con el texto indicado hasta alcanzar esa longitud. Si se omite el segundo parámetro, el relleno es un espacio en blanco.

ExpresiónValor devueltoExplicación
"5".padStart(2, "0")"05"Rellena con un 0 hasta longitud 2
"5".padStart(4, "0")"0005"Rellena con tres 0 hasta longitud 4
"12".padStart(2, "0")"12"Ya tiene longitud 2, no se toca
"9".padStart(3, "-")"--9"El relleno puede ser cualquier texto
"hola".padStart(8, "*")"****hola"Se repite el relleno si hace falta
"7".padStart(3)"  7"Sin segundo parámetro rellena con espacios

Detalle imprescindible: hay que aplicar String(...) antes de padStart(), porque los getters de Date devuelven números y el método padStart solo existe en las cadenas.

Comprobaciones

Ventaja frente a un lenguaje tradicional

En JavaScript la interpolación de plantillas (`${dia}/${mes}/${anio}`) resuelve la concatenación directamente, sin necesidad de declarar el tipo de cada dato ni de concatenar de forma explícita con el operador +. En C o C++ traditional habría que declarar la clase, definir el método ToString() o usar stringstream; en Java, invocar String.format() con la máscara %02d. En un lenguaje de script la versión dinámica de esta función son cinco líneas.
